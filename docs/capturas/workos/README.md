# Capturas do WorkOS com a nova moldura

Capturas feitas com Chromium headless a 100% (1366×768, 1920×1080 e 390×844) e uma variação a 125%. O conteúdo de teste usa janelas reais criadas por `osWindow()`, com conteúdo HTML dinâmico; os nomes e textos internos são fixtures visuais.

- `janelas-1366.png`: duas janelas sobrepostas, uma ativa e outra inativa, com conteúdo longo.
- `janelas-1920.png`: validação em viewport ampla.
- `maximizada-1366.png`: janela maximizada sobre a área de trabalho.
- `janela-mobile.png`: janela em viewport móvel com a barra de tarefas.
- `confirmacao.png`: janela compacta de confirmação.
- `zoom-125.png`: escala de navegador a 125%.
